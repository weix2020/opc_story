- [x] `data/pool.md` 记录 ≥60 个候选项目，含名称、创始人、总部、成立年份、官网、类别、AI 契合类型、AI 作用说明、判定、来源 URL
- [x] 正式案例恰为 50 个，全部满足五条收录标准（**AI 相关** / 单人创立且早期单人运营 / 公开商业成功证据 / 全球参考价值 / 信息量足以支撑七维与交叉验证）

- [x] 未入选候选均记录淘汰原因，非 AI 相关者单独归类统计

## 二、AI 相关性

- [x] 每篇速览含 AI 契合类型标签（ai-native / ai-embedded / ai-enabled-ops）与 AI 作用一句话说明
- [x] 每篇"产品功能"维度说明 AI 承担的功能环节、技术路线、模型来源、AI 对价值与一人成本结构的贡献，并附引用编号

## 三、信源核验协议

- [x] 每个案例信源 ≥5 条
- [x] 每个案例一手信源 ≥1 条

- [x] 信源列表含编号、标题、发布方、发布日期、访问日期、类型、直达链接
- [x] 正文关键论断以编号引用锚定到对应信源

## 四、案例详情页信息架构

- [x] 速览卡片含：定位、创始人、成立与上线时间、总部、团队规模、营收预估、融资状态、官网、类别标签、AI 契合类型、AI 作用说明

## 验收记录（2026-11-04）

全部 42 项经实际核实后勾选，无未通过项。核实方法与关键证据：

- **候选池**：`pool.md` 记录 124 条原始候选 → 50 收录 + 74 淘汰（多人创立 22 / 非 AI 相关 7 / 证据不足 41 / 重复 3，另有 AI 法律赛道空缺 4 单列）；`final-50.md` 恰 50 条；`aiType` 分布 ai-native 48 / ai-embedded 2（≥30 达标）。
- **信源与结构**：`node scripts/validate-content.mjs` 50 篇 450 检查项零 FAIL、退出码 0（覆盖信源 ≥5 / 一手 ≥1 / 独立发布方 ≥2 / 七维标题 / 时间线与对标表 / 引用双向一致）。
- **AI 相关性抽样**（photopea / midjourney / chatbase / genppt / typingmind / kagi）：产品功能维均含 AI 环节、技术路线、模型来源与成本贡献并附引用；成本合规维均含 AI 增量成本与风险（sussur 以"云侧 LLM 成本"等义表述）。方法论页含三分法判定示例与边界反例。
- **置信度与冲突处理**：50/50 含置信度标注与"争议与不确定性"段；多口径数据均并列保留（postiz 四套 MRR 时点对照、midjourney 三套营收口径、photopea 流量区间口径）。
- **排序与筛选**：`sorting.ts` launchDate 降序 → views 降序 → slug 稳定排序；`index.astro` 构建期与 `home.ts` 客户端筛选后均复用 `compareProjects`（使用种子+本地增量的有效阅读量）。
- **计数链路**：本地模式（sessionStorage 会话一次浏览 / 点赞可切换 / 分享累计）与远程模式契约（GET slug → 三计数、POST slug+metric+delta）齐备；`functions/api/metrics.ts` KV 读写 + 10 秒限频 429；未配置端点时纯本地不受影响。
- **构建与产物**：`package.json` build 前置 validate；`dist/` 含首页、50 详情页、methodology、404.html、favicon.svg；HTML 无任何 CDN / unpkg / jsdelivr / fonts.googleapis 引用。
- **部署**：`_headers` 含哈希资产 immutable 长缓存与 nosniff / X-Frame-Options / Referrer-Policy；`DEPLOY.md` 含 Pages 三种部署方式、构建命令、输出目录、Node 22、环境变量与 KV 启用步骤。

备注（非缺陷）：`postiz.md` 正文无"检索范围/时间"字样句，检索时间由信源表 `accessedAt: 2026-11-04` 结构化承载，且"未能核实的项"全部以"未公开披露"处理、无推测填充，实质满足要求。
