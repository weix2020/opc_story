案例档案

Case Profile

Cherry Studio 是一款开源跨平台多模型 AI 桌面客户端，支持 Windows、macOS 与 Linux，定位"一个入口、连接所有 AI"：聚合 300+ 主流模型、内置知识库、智能体（Agent）与 MCP 协议支持[1][2]。本案例是案例墙中"一人属性"最需要诚实降级的样本——项目长期以"两人兼职团队"口径自述起步，随后经开源社区共创走向公司化融资；案例墙收录的是其 2024 年（▲年锚点）个人/双人副业起步阶段的早期形态[3]。

项目
Cherry Studio（CherryHQ/cherry-studio）：AI 工作站式桌面客户端——多模型对话、多模型同问对比、本地/云端知识库（含 OCR 与文档解析）、智能体与自动化（Skills、MCP、定时任务、Channels）、图像生成、翻译、语音、API Gateway，数据本地存储并支持 WebDAV 备份；已扩展 iOS/Android 移动版（独立仓库 cherry-studio-app）。
信源：[2]
创业者
GitHub 项目第一贡献者为 kangfenmao（网名"亢奋猫"，GitHub 主页自称"亢奋猫 / Software Engineer"，坐标上海，账号注册于 2014 年）。其网名与运营公司工商登记姓名的逐一对应未获直接公开信源确认，真名未公开——按"项目第一贡献者 kangfenmao / 工商登记创始人王新铭"双口径如实呈现（详见捌）。
信源：[4] [5] [6]
公司主体
上海千彗科技有限公司：天眼查品牌页显示成立于 2025-01-09、所属地上海、当前融资轮次为种子轮，定位"跨平台多模型 AI 桌面客户端开发商"；工商登记核心人员为创始人王新铭、联合创始人王谦。王新铭，1990 年生于山东临沂，曾在喜马拉雅 FM、依图科技、字节跳动及 PPTV 等公司从事产品工作，曾在新能源创业公司担任产品合伙人。
信源：[5] [7]
团队口径（本案例关键）
案例墙底稿口径："自述长期'两人兼职团队'起步（一人属性打折）"。自媒体长文转述创始人自述："白天我们各有各的工作，晚上就全职扑在 Cherry Studio 上""每天只睡四五个小时"；2025 年 DeepSeek 爆火后于年中转型全职，团队从 2 人扩至 9 人（自媒体转述口径，2026 年初 42k★ 时点）；至招聘简介期已为公司化运作。

案例墙收录标准强调个人开发者属性，而本案例底稿已明确标注"自述长期'两人兼职团队'（一人属性打折）"、置信度"中"，且案例墙检索说明中注明"Cherry Studio 按公司化口径曾排除"，最终以早期副业形态收录。本报告遵循该口径：将 Cherry Studio 定位为"两人兼职起步 → 社区共创 → 公司化"的演进样本，而非严格意义的"一人公司"；其价值在于展示开源 AI 客户端赛道从个人项目长成公司的完整路径，同时为"一人公司"概念划出真实边界。

创业路径复盘

Key Turns
转折一：产品老兵的"聚合"执念——不造模型，造入口
创始人（王新铭，工商口径）的履历横跨喜马拉雅、依图科技、字节跳动与新能源创业公司——依图经历让他"第一次意识到 AI 真的要改变世界"，字节经历让他思考"AI 的 C 端产品应该长什么样"（自媒体转述其播客访谈口径）。创业切入点刻意避开模型层：不做"中国版 ChatGPT"，而做聚合所有模型的桌面入口，解决"在不同 AI 工具间切换、复制粘贴上下文"的碎片化痛点。这一"入口卡位"思路在其后的五源播客中被提炼为"被'套壳'二字掩盖的独立价值"。
信源：[8] [7] [10]
转折二：DeepSeek R1 引爆——外部模型事件成为开源项目的"顺风"
2025 年 1 月 20 日 DeepSeek R1 发布，成为本案例的显性引爆点：用户量暴涨、服务器访问量周末翻 20 倍、Issue 与 PR 爆炸。对二人兼职团队而言，这既是增长红利也是运维危机——"有些 Issue 挂了三个月都没人处理""服务器账单每个月都在透支信用卡"（自媒体转述口径）。这段"红利即压力"的经历说明：开源客户端的命运与模型层事件高度联动，个人/小团队必须提前设计承接增长的社区机制。
信源：[8]
转折三：从"两人兼职"到公司化——一人属性的终点，开源社区的杠杆
与案例墙多数"一人到底"的样本不同，本案例的路径是主动升级组织形态：2025 年中转全职 → 团队 9 人（2026 年初口径）→ 千彗科技公司化（2025-01 注册）→ 获五源、光合数百万美元投资 → 2026 年以"AI Native 公司"身份招聘扩张。开源社区是这一升级的杠杆：417 名贡献者分担了代码、文档与翻译；自媒体转述的社区运营细节包括为核心贡献者报销 Cursor 订阅（每月约 70 美元）、以美团外卖犒劳深夜加班者、"核心贡献者一半以上是研究生"——用小成本把社区热情转化为可持续贡献。
信源：[8] [6] [5] [9]

产品与商业模式

Product & Business
维度内容信源
产品功能矩阵桌面端（Windows/macOS/Linux）+ 移动端（iOS/Android）：①多模型聚合对话——接入 OpenAI、Anthropic、Gemini 等云服务商与自定义兼容服务，支持 Ollama/LM Studio 本地模型，同一会话多模型并排对比；②智能体与自动化——自定义 Agent（指令/工作区/模型/工具权限）、文件与浏览器操作、Skills 与 MCP 服务器扩展、定时任务、消息平台 Channels；③知识库——本地文件/文件夹/网页构建，PDF/Office/图片解析与 OCR，用于对话与 Agent 工作流；④创作与效率——图像生成、翻译、联网搜索、Mini Apps、API Gateway；⑤语音与工作区——语音输入/TTS（含本地模型）、多标签与独立窗口、主题生态、本地数据与 WebDAV 备份。[2][1]
开源 + 商业服务模式社区版完全免费开源（AGPL-3.0），个人使用免费，商业使用须遵守 AGPL 条款，需豁免者购买商业授权（官方预留 bd@cherry-ai.com 商务通道）；企业版（enterprise.cherryai.com）：集中模型管理、共享知识库、员工访问控制、私有化部署。官网另设"免费模型合作伙伴"导流（BigModel GLM-4.5-Air、SiliconFlow Qwen3-8B 等，免 API Key 体验），README 中的 API Gateway 用于将用户自配模型接入其他应用。关于"API 服务"：未检索到官方对外售卖自有 API 服务的公开信源，官网免费模型为合作伙伴提供；商业模式以"开源社区版 + 商业授权 + 企业版"为准（公司自述口径）。[2][1]
面向客群三层客群：①大众用户——早期用户大量为非技术背景（老师、销售、自由职业者，自媒体转述口径），"下载安装、填 API Key 即用"的零门槛定位；②开发者与重度用户——多模型对比、MCP/Agent、本地模型与数据主权；③企业客户——企业版的集中管理与私有化部署（商业授权与商务通道）。融资方叙事进一步把定位提升为"AI Native 组织的入口级交互界面"（公司招聘自述口径）。[8][2][9]
解决痛点①多 AI 服务割裂——"一个窗口聚合所有 AI"，免去多平台登录与上下文搬运（自媒体转述的创始动因）；②门槛——零配置起步，另有合作伙伴免费模型免除 API Key 环节；③隐私与数据主权——本地模型接入、对话与知识库本地存储、企业私有化部署；④"套壳"质疑下的工程整合价值——智能体、MCP、知识库等深水区能力构成模型层之上的独立价值（五源播客叙事）。[8][1][10]
💡 模式解读：AGPL 双刃剑
AGPL-3.0 对个人与社区友好（永远免费），对企业则构成合规门槛——任何对 Cherry Studio 做商用分发的公司要么开源其修改，要么购买商业豁免授权。这把"开源 popularity"直接转化为企业版/授权收入的谈判筹码，也是开源客户端赛道中较罕见地把许可证本身用作商业杠杆的打法（对比案例墙中 ChatWise 的个人闭源买断、NextChat 的纯开源路线）。

LobeChatarvinxx 等（双人起步）开源 AI 聊天/Agent 平台—8.4 万★双人起步、已公司化融资（案例墙观察名单）[13]

"开源社区驱动 vs 单人维护"的差异是本组对标的核心变量。NextChat 以单人之力做到 88.8k★，是"单人开源影响力"的天花板样本，但维护带宽受个人时间约束；ChatWise 走单人闭源买断，无社区贡献杠杆，换来的是直接的现金流而非星标；Cherry Studio 与 LobeChat 则代表另一条路径——用开源许可证与社区机制把维护成本外部化给数百名贡献者，再以商业授权/企业版回收价值，最终走向公司化。值得强调的是：LobeChat 因"双人起步、已公司化"被案例墙列入观察名单，而 Cherry Studio 以"两人兼职团队"口径收录主线——两者的边界处理逻辑一致：开源 AI 客户端赛道中，"纯粹的一人公司"极其罕见，星标与下载量的规模化几乎必然撬动社区协作或资本，这是个人开发者案例向"超级个体→小团队"演进的结构性信号。

对本案例的一人属性，报告如实降级讨论：Cherry Studio 的"成功"不能简单归因于"一个人"——它的第一贡献者 kangfenmao 个人提交量（2,444 次）虽居首位且远超第二名，但 417 名贡献者的社区合力、以及 2025 年后的公司化组织，共同构成了产品的持续交付能力[6][8]。案例墙收录其价值恰在于此：它示范了个人开发者把副业项目做成"社区级开源资产"后，可选的三条变现与组织路径（授权、企业版、融资）。
