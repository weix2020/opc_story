案例档案

Case Profile

Raphael AI 是 2025 年初上线的基于 Flux.1-DEV 的免费无限制 AI 文生图出海站，以"完全免费、无需注册登录、无使用次数限制"三个卖点在红海赛道撕开缺口，上线初期月活即破百万；其创始人刘小排同期的产品矩阵还包括用 Claude Code 全 AI 开发的图/文秒级生成 3D 模型站 Fast3D 与声音克隆站 AnyVoice。按案例墙"一人一案例"惯例，本报告将 Raphael AI 与 Fast3D 两条产品线合并呈现。

产品线一：Raphael AI（raphael.app）
2025 年 1 月 16 日在 V2EX 发布，自我定位"世界唯一完全免费、无限制、无需要注册登录、基于 Flux.1-DEV 的 AI 图像生成器"；支持垫图参考、多种风格/色调/光照/构图参数与中文提示词，生成图片 10 分钟内从服务器删除。[3] 上线初期获"一个月月活破 100 万、全球 AIGC 产品增长榜第 15 名"的增长战绩[8]。
信源：[3] [8] [9]
产品线二：Fast3D（fast3d.io）
文字描述或图片秒级生成 3D 模型的出海站，媒体口径"8 秒造物"：将 3D 建模成本降至传统方式（单个 60-1500 美元、耗时数周）的约 1%，支持最高 40 万面精细建模，覆盖游戏、3D 打印、AR/VR、工业设计场景。[6] InfoQ 明确口径：该产品"完全用 Claude Code 做了 Fast3D"；刘小排自述其 3D 模型为自研自训，因此"敢提供免费使用"。[2][1]
信源：[6] [2] [5]
创业者：刘小排（连续出海产品创业者）
1987 年生，重庆人，重庆大学 2009 年本科毕业；曾任猎豹移动产品总监整整十年，2024 年 12 月 31 日（工作满十年当天）离职创业。[1] 非程序员出身，2021 年加入生财有术社群，试水无人直播、外卖红包、发传单等项目累计获利近 100 万元，成为后续创业底气。[2]
信源：[1] [2]
公司 / 融资 / 团队状态
无融资，且"不打算融资"；2025 年 9 月口径：按市场价格收入"可以养三五十个人没问题"，但公司只有六七个人（AI 工具用得多）；公司无 KPI、无 OKR、无周报月报。[1][2] 一人属性存在时变：创业初期"团队中唯一的人类员工，其余工作均由 AI 承担"[2]，至 2025 年 7 月媒体报道"团队已经有 7 个人"[6]。另有知识产品线：AI 编程课 Idea to Biz、与生财有术合作课程并共同发起 AI 产品孵化器 SCAI 实验室。[2][10]
信源：[1] [2] [6]

创业路径复盘

Key Turns
转折一：近百万元的"贴地试错"垫底，需求洞察成为真正的护城河
刘小排的启动资金与手感来自生财有术时期的密集试错——无人直播、外卖红包、发传单，累计获利近 100 万元[2]。他总结的需求方法论：关注热门事件带来的瞬时供需失衡、找"下载量大但评分只有 2.6 分"的商业逻辑成立但解决方案差的应用、直接翻社交媒体上"希望有个 XX 软件就好了"的帖子；"创业不是盘点技能树然后推演出方向，创业是先看见问题，再决定用什么能力去解"。[10] 当 AI 抹平编程门槛后，"找到真问题"取代"会写代码"成为新的分水岭[2]。
信源：[2] [10]
转折二："免费无限制"不是烧钱换增长，而是一次成本套利
Raphael 上线时敢于"世界唯一免费无限制"的底气是几块闲置一年的 A100——"也就是电费成本而已"[3]；Fast3D 敢免费的底气则是模型自研自训省去了 API 采购成本[1]。免费端用"排队"控制体验成本，付费端用"免排队、5 倍速度、更高质量、无水印"收溢——这套"免费用户排队、付费用户免排队、出图更快、质量更高"的变现点设计，成为其方法论的标准件[2]。所谓红海，在成本结构被重构后就不是红海。
信源：[3] [1] [2]
转折三：从"我用 AI"到"AI 替我"——把公司做成自动售货机
他把 AI 编程分为六阶段：前三阶段（v0/Bolt、Cursor、VS Code+插件）是"赛博摆摊区"，手停口停；后三阶段（Claude Code、Claude 实习生、OpenAI Codex 全职员工）是"自动售货机区"，分水岭在 Claude Code 出现。[10] 他用 Codex 替代了自动产品优化、写日报、监控竞品、自动发公众号等约 12 个"岗位"，以"岗位说明书→AI 跑一遍→改 SOP→稳定一周即外包"的流程复制；2026 年 2 月整月不开电脑业务仍增长。[10] 组织侧的对应物是"无 KPI、无 OKR、无周报月报"的六七人公司[2]。
信源：[10] [2]

七维深度分析

Seven Dimensions
维度分析信源
1. 产品功能与定位"免费无限制免注册"的文生图工具站 + 自训模型 3D 生成站 + 声音克隆站的出海产品矩阵，叠加课程/孵化知识产品线；单点极简（进站即用）、矩阵互导（Raphael 菜单直跳 AnyVoice）。[3] [9]
2. 面向客群C 端海外发达国家用户为主（95% 海外流量为社区观察口径）；Fast3D 面向游戏/3D 打印/工业设计等泛专业人群；知识产品面向国内独立开发者圈层。C 端定价低客单、高流量摊薄成本，是典型工具站经济。[1] [11]
3. 解决痛点供给侧：主流 AI 绘图"收费昂贵或严格限制"、传统 3D 建模单个 60-1500 美元耗时数周；需求侧：把"数周 + 千美元级"压缩为"8 秒 + 成本 1%"，把注册墙、付费墙全部拆掉，实现技术普惠式体验。[3] [6]
4. 免费模式的成本结构（推理成本）关键在把边际成本压到近零：起步靠闲置 A100 的"电费成本"[3]；Fast3D 靠自训模型省去 API 采购[1]；运行层用 Cloudflare 人机验证防刷量[9]、免费档限速排队 + 512px/水印控制单次产出价值，付费档（5 倍速度/HD/无水印）承接溢出需求覆盖推理账单[9][4]。免费不是补贴，是分层定价的低价档。[3] [9]
5. Flux 开源模型的合规使用Raphael 早期基于 BFL 的 Flux.1-DEV 自建推理（"Powered by Flux.1 Dev"为官网四大卖点之一），以"任何创新都站在前人的肩膀上"姿态做工程化转化；但基于该模型自建 API 对外提供服务的许可合规安排（商用授权、水印与署名要求等）未检索到公开披露信息，属本案留白。[3] [8] [1]
6. 营收自述口径"2024 年接近 1000 万元"为自述（InfoQ 转述）[2]，广工官网"年入千万"为高校宣传转述口径[7]，两口径同向但均无审计；可交叉的旁证是收入"可养三五十人"而公司仅六七人[1]。对照"多数一人公司年收入上限 500 万-2000 万元"的行业观点，该数字量级可信但精确值不可验证[13]。[2] [7] [13]
7. 增长方法论与可持续性工具站 2.0 落地页 + 27 种语言子页面 + 高权重友情外链（Pollo AI、HIX.AI、MCP.so 等）构成 SEO 引擎[9]；可持续性取决于两点：模型代际更替能力（Flux.1-DEV → GPT Image 2.5/Seedream，已验证迁移）与免费体验护城河的模仿门槛（后继者 Inkfox 照抄 tagline 五周仅数百用户、两单订阅，说明打法可复制、壁垒不可复制）[11]。私域侧，其公众号内容（如《Grok Bot才是Jarvis》）被金马博客等独立开发者持续自发引述推荐，构成低成本的圈层传播资产[12]。[9] [11] [12]

本案的样本价值
Raphael AI 证明了 OPC 模式在"工具型出海"赛道的标准打法闭环：用闲置资源重构成本结构（闲置 A100 = 电费）→ 用免费无限制击穿行业付费墙共识 → 用订阅 + 广告把流量换成现金 → 用同一套 AI 工作流（Cursor → Claude Code → Codex 数字员工）把复制新产品的边际成本压到趋零，三年滚出 50 款产品的矩阵。它与《归墟》类"作品型 OPC"互为镜像：一个把 AI 当生产力卖铲子，一个把 AI 当画笔做作品。而其争议（自述营收、社区榜单、口径打架）也同样是 OPC 研究的方法论样本——个人叙事时代，交叉核验比故事本身更重要。[1] [2] [10]
