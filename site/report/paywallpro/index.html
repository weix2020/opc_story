案例档案

Case Profile

PaywallPro 是一款面向出海订阅制 App 团队的「付费墙情报调研平台」：收录真实 iOS 应用的付费墙截图、Onboarding 引导流程、定价与历史版本数据，并提供 AI 变现建议。创业者对外以「鱼总聊AI」示人（X 账号 @AI_Jasonyu，Product Hunt 署名 Jason Yu），2026 年 4 月起以「一人 + AI」的超级个体模式运营。需要特别说明：本案例运营数据几乎全部为本人自述口径，无第三方审计或主流媒体报道。

产品
一站式付费墙情报平台。官网当前口径：追踪订阅应用 4,076+ 款、付费墙截图 129,044 张、用户引导流程视频 5,513 条、每周新增 350+ 张截图；对外发布口径为「46,000+ iOS 付费墙截图 + 2,000+ Onboarding 流程、服务 2,000+ 应用」。多语言站（中/英/日/德）。

创业路径复盘

Key Turns
转折一：从「凭截图找灵感」到「把设计和收入关联」——产品定义的升维
市面上并不缺付费墙截图站，缺的是「哪个改动赚钱」的证据。鱼总的上线路由头自述：曾把 400 款订阅 App 塞进手机逐一研究，结论是「光看截图根本没用」——于是把产品定义为「情报」而非「图库」：截图之外叠加历史版本、定价/试用变化与 RPD、ARPU 等收入信号，再用 AI 生成个性化变现建议。8 年出海订阅 App 的产品经理履历（PH 自述）构成其对「设计—收入」因果链的行业判断力，这是产品差异化的真正来源。
信源：[8] [6] [4]
转折二：组织形态的「两进两退」——公司化被两次证伪
2023 年招 4-6 名实习生做自媒体矩阵，账号「没流量的没流量，封的封」，以产品利润养自媒体而告终；2024.03 再次成立公司，两年后（2026.04）因亏损解散。个人站将其总结为「团队不一定放大你，可能先放大你的开销」，并由此确立当前形态：一个人 + AI 工作流，目标是「一个人，干出一支小团队的产出」。这一反复试错的组织收缩路径，是 OPC 案例中少见的如实公开「公司化失败」的样本。
信源：[1] [3]
转折三：数据画廊引流——把商业数据库的「样品」开放出去
获客打法上，PaywallPro 没有投放记录（自述全自然流量），其引擎是三件事：① GitHub 开放数据集（paywall-gallery，从 HN 提交时的 500 款扩至当前 README 口径 1,710 款，中英双语 README，承诺每周新增 50 款）作为一手数据资产换取开发者信任与外链；② X 内容营销——出海基础设施教程（eSIM 写卡、保号攻略）自述阅读量百万级，把个人 IP 流量导向产品；③ 免费钩子——免费版每日可看 5 条、免费 AI 小工具（汇款计算器等）沉淀长尾搜索。三者共同指向同一目标客群：做出海订阅 App 的开发者。
信源：[9] [10] [1] [6]

我受够了靠感觉赚钱，所以花了一年半做了 PaywallPro。它的核心就是把【设计】和【收入】关联，让你看清楚：什么改动能赚钱，什么改动在赔钱。

面向客群出海订阅制 iOS App 的开发者、产品经理、增长团队与设计师；官网自述「2,000+ 应用信任」；PH 分类归入设计灵感/商业智能/用户研究[4][6]
解决痛点海外订阅市场定价与付费墙设计「无参考」：成功应用如何定价、高转化付费墙长什么样、该不该 A/B 测试新版本——过去只能凭感觉或零散截图，现在以结构化数据 + AI 建议回答「下一步测试什么」[6][8]
商业模式要点
PaywallPro 的本质是「竞品情报 + 数据基准」生意，与 App Store 生态的第三方分析服务（如数据平台提供的榜单与收入预估）互补而非同类：它卖的不是自家收入数据，而是「别人家的付费墙长什么样、改了什么、价格怎么变」的过程数据。数据采集端由「自动化抓取 + 人工 QA」完成（PH 评论区口径），这也构成了柒节讨论的合规边界问题。

七维深度分析

Seven Dimensions
维度分析
1. 产品功能三层结构：收录层（竞品付费墙截图/视频/历史版本与 A/B 变体）→ 分析层（Onboarding 流程对比、定价与试用策略演变追踪）→ 建议层（AI 生成个性化变现建议、RPD/ARPU/转化基准对比、what-if 定价模拟 Roadmap）。功能闭环完整，属于「数据 + AI 解释」的情报型产品。[4][6]
2. 数据资产与护城河129,044 张截图、5,513 条 Onboarding 视频、历史版本库是核心资产；每周 350+ 张的持续采集构成时间序列壁垒（单张截图易抄，连续三年的定价演变史难抄）。GitHub 开放画廊既是获客漏斗也是资产展示。护城河真实存在，但依赖持续采集投入——单人 + 自动化工作流能否长期维持更新频率是关键变量。[4][9]
3. 变现模式Freemium 订阅（免费每日 5 条 → Pro/Team 订阅），价格未公开；创业者收入结构多元化：X 内容变现（自述约 20 万元/7 个月）+ 社群（¥99）+ 杂货铺与返佣 + 产品订阅。值得注意的是「IP 变现先于产品变现跑通」——X 是自述的主要收入来源之一，产品更多是 IP 信任的变现出口之一。[6][1]
4. 面向客群出海订阅制 App 的开发者/PM/增长团队/设计师，以海外市场为主（多语言站、丹佛注册主体、海外发布渠道）；中文侧通过个人 IP 反向辐射国内出海圈。客群与 PaywallPro 数据库内容（Duolingo、CapCut、Tinder、Flo 等头部订阅应用）高度匹配。[4][5]
5. 解决痛点订阅制 App 的定价与付费墙决策长期「凭感觉」：高转化付费墙长什么样、头部应用价格怎么调、A/B 测试值不值得做。PaywallPro 以真实竞品的过程数据回答「下一步测试什么」，把设计决策从灵感驱动改为基准驱动——痛点真实，且随 iOS 订阅生态内卷而放大。[6][8]
6. 预估年化营收（推算，置信度 C）无任何可核验的收入拆分。可用的自述锚点仅两条：单款营收 $200k+（自述，且 $120k→$200k 口径演进）与 X 变现约 20 万元/7 个月（自述）。若 $200k 为 PaywallPro 单款累计口径，按发布期 2025-10 起算年化约 $150k-200k 量级；按 PH 44 upvotes / 0 评测的冷启动热度看，B 端订阅收入增长仍处早期，X/IP 收入占比可能不低于产品订阅。以上均为 C 级推算，仅供参考。[1][3][6]
7. 投入成本与合规风险App Store 数据抓取合规：竞品付费墙截图与 Onboarding 视频的规模化采集处于灰色地带——采集行为是否违反相关应用服务条款、截图与 UI 设计的版权边界、商业数据库的合理使用范围，均未检索到公开的法律口径或权利方主张；PH 口径为「自动化采集 + 人工 QA + 合作方投稿审核」，即采集工程化本身已被承认为核心能力，但合规依据未公开。X 平台内容营销可信度：增长高度依赖自述式复盘与教程带货（eSIM 卡、U 卡等自营杂货铺商品），「X 阅读 260 万+」等数据同为自报；HN 宣发被 flagged 亦提示海外社区对自我推广的敏感。主体风险：美国主体（丹佛地址）注册地与实际运营地的跨境披露口径模糊。[6][10][5]

PaywallPro 代表了 OPC 的另一条非典型路径：不卖自己的产能，卖行业的「过程数据」。它把一人公司的劣势（无法覆盖大客户、无法拼投放）转化为优势——单人 + AI 自动化采集恰好匹配「长周期、低边际成本、靠时间复利」的数据资产生意；个人 IP（X 教程）承担了传统 SaaS 的市场费用职能。同时它也是一面诚实之镜：创始人公开留下公司化两次失败的记录，提醒「超级个体」不是情怀口号，而是被组织成本反复证伪后的理性选择。
