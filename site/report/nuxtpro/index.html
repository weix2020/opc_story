案例档案

Case Profile

NuxtPro 工具矩阵是国内独立开发圈「一人多产品 + 公开记录式运营」的代表性样本：创业者以即刻（jike）为主阵地、以 Twitter/X 为获客渠道，同时维护 SaaS 模板、AI 大模型网关、导航站与若干工具站。其「每月至少 1 万美元额外睡后收入」的说法全部出自本人自述，本报告逐条核验后确认：无一独立第三方信源交叉印证。案例墙对该案例的置信度定级为「中」。

产品矩阵（2026-11 实测口径）
核心两款：NuxtPro——基于 Nuxt3 的出海 SaaS 模板，开源免费版 + $158 买断商业版双轨；CodeProxy——AI 大模型网关（Codex / Claude Code 订阅中转，¥79-1299/月多档）。外围产品：AI 产品导航站 NuxtDir、临时邮箱 FreeTempMail、Sora 视频去水印工具 Remover.plus（域名已过期）、研发中的开源 GEO 产品 GeoHi。即刻 2025-11 长帖中还列有「CheapGpt：AI API 中转服务」。

创业路径复盘

Key Turns
转折一：把「销售」放在「写代码」之前
其即刻高赞帖（176 赞）给出方法论：「程序员转做独立开发的第一件事：忘掉自己是个程序员，把自己当作一个销售一样去卖一个尚且还不存在的产品。如果这个时候都有人来问你、咨询你多少钱的时候，你就可以开始 vibe coding 了。」这与官网自述「每年用 2-3 个月假期发现痛点」一脉相承——先验证需求、再投入工程，是其多产品快速试错的底层逻辑。
信源：[1] [2]
转折二：把重复了三次的基建，变成卖 $158 的商品
18 个月、3 个 SaaS 项目、三次重写 OAuth / Stripe Webhook / 多租户权限（自述约 12 周沉没成本）之后，他选择把这套基建封装为 NuxtPro：定价 $158 买断，显著低于 Supastarter（$349）与 Nuxt UI Pro（$249-999），以「Vue/Nuxt 生态缺模板」的空档切入（竞品 MkSaaS 为 $169 但基于 React）。开源免费版承担获客与信任建设，商业版承担变现——「开源引流、付费转化」的漏斗结构成型。
信源：[7] [2] [4]
转折三：矩阵的新陈代谢——现金流接力棒交到 CodeProxy
2026 年的可观测事实：NuxtPro 仓库自 2026-06-28 后无新提交、NuxtDir 热榜区域空置、Remover.plus 域名过期停摆；与此同时 CodeProxy 成为即刻主页置顶主推（双十一充值促销、主打「稳定可开票」、企业对公合作），GeoHi 进入内测。「多产品分散风险」策略的另一面在 2026 年显形：一个人的维护精力被摊薄，产品群呈现明显的生命周期分化——模板滞涨、工具站死亡、网关接力。
信源：[3] [10] [11] [1]

七维深度分析

Seven Dimensions
维度分析
1. 产品功能三层结构：流量层（NuxtDir 导航 / Remover.plus、FreeTempMail 工具站 / 开源仓库）→ 转化层（NuxtPro 开源免费版建立信任）→ 变现层（$158 买断模板 + CodeProxy 订阅/按量网关）。模板预集成 Stripe/Waffo Pancake 支付、BetterAuth 登录、i18n、SEO 博客管理与 PWA；网关提供 Codex/Claude Code 分档订阅、模型价目对比与用量可视化。[2][8]
2. 面向客群模板客群为 Vue/Nuxt 技术栈、预算敏感的独立开发者与中小出海站长（$158 显著低于 $249-349 竞品价格带）；网关客群为「不能上外网的企业和开发者」（其即刻原话），主打对公转账、发票与合同——瞄准国内企业接入海外模型的合规支付需求；导航站客群为需要冷启动外链的 AI 产品开发者。[2][1][8]
3. 解决痛点模板侧：Vue 生态 SaaS 模板空缺（主流样板 MkSaaS/Supastarter 均为 React 系），自述省 4-6 周/约 198 小时基建工时；网关侧：国内支付方式、发票与稳定性三重门槛；工具站侧：Sora 水印、临时邮箱等即时需求。痛点的共同特征是「小而高频、大公司看不上」。[7][1]
4. 预估年化营收（推算，置信度 C）唯一锚点为自述「≥$10k/月」，上限口径年化 ≥$12 万美元；构成无法拆分——模板买断（$158×客户数）、网关订阅（¥79-1299/月×档位）、按量计费三块的占比均未披露。网关业务按其官网价目推算：若 Standard Codex（¥199/月）客户 200 人即约 ¥4 万/月流水，但客户数零披露。2026 年无任何自述更新，该数字是否持续完全无法验证。本项推算仅供参考，不构成事实陈述。[2][4][8]
