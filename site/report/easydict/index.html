案例档案

Case Profile

Easydict 是一款「简洁优雅」的 macOS 词典翻译应用：开箱即用、自动识别输入语言，支持输入翻译、划词翻译与 OCR 截图翻译，可同时并列查询 20+ 个词典、翻译、AI 与本地模型服务[1][2]。它由国内开发者 tisfeng 一人主导开发维护，以 GPL-3.0 协议完全免费开源，是案例墙中「免费开源工具对标付费产品」的典型样本。

产品
macOS 菜单栏词典翻译 App：默认快捷键 ⌥+A 输入翻译、⌥+D 划词翻译、⌥+S 截图翻译、⌥+⇧+S 静默截图 OCR（识别结果直接进剪贴板）；支持有道词典、苹果系统词典、苹果系统翻译、OpenAI、Gemini、DeepL、Google、Bing、腾讯、百度、阿里、小牛、彩云、火山等 20+ 服务，52 种可选翻译语言，多 TTS 发音[1][2]。当前版本要求 macOS 13.0+，旧系统可使用 2.7.2 版[2]。
信源：[1] [2]
创业者
tisfeng（真名未公开，GitHub 显示名与 V2EX 账号 isfeng 同源），GitHub 资料显示位于中国，2017 年 1 月注册，57 个公开仓库、403 名关注者，bio 为「null & void」[3]。README 自述项目「currently mainly developed and maintained by the author」（主要由作者本人开发维护）[2]。
信源：[3] [2]
分发与安装
Homebrew 官方 cask 一行安装（brew install --cask easydict，当前收录版本 2.25.0）[4]，或从 GitHub Releases 下载 DMG[2]；另有社区开发的 Raycast 扩展版「Easy Dictionary」（41,844 次安装）[5]。
信源：[4] [5]
商业化状态
完全免费，无付费版本、无内购、无功能墙（第三方评测口径「Free — no tiers, no trial, no paywalled features」）[6]。README 声明「任何人都可以免费获取本产品与源代码」，赞助渠道为爱发电页面[2]；赞助金额与项目收入未检索到公开信息。无融资记录。
信源：[2] [6]

创业路径复盘

Key Turns
转折一：站在 Bob 的肩膀上——GPL 分叉起步
Easydict 并非从零造轮子。README 致谢部分明确写道：项目灵感来自 saladict（沙拉查词）与 Bob，「初始版本基于 Bob（GPL-3.0）开发，Easydict 在原项目基础上做了大量改进与优化，许多功能和 UI 参考 Bob」；截图功能基于 isee15 的开源项目优化，划词参考 PopClip[2]。正因为 Bob 同为 GPL 开源，这次「分叉再出发」在协议上完全合规——开源社区的开源协议，为一个更激进的免费产品提供了合法起点。2023 年 4 月 V2EX 帖中已有用户一语道破「怪不得感觉跟 Bob 这么像」[7]。
信源：[2] [7]
转折二：把 LLM 翻译塞进传统词典壳——AI 契合点的准确押注
ChatGPT 出圈后，划词翻译工具的最大变量是「大模型翻译质量超过传统引擎」。Easydict 的服务列表从最初的有道/苹果/DeepL/Google/Bing 等传统引擎，逐步扩展到 OpenAI、Gemini、Claude、DeepSeek、智谱、Groq，再到 Ollama 本地模型乃至 Claude Code、Codex CLI 等命令行智能体[2][11]。掘金转载的 DeepSeek 官方「实用集成」文档亦将其收录为大模型 API 翻译的接入端[11]。工具的壳是 2022 年的，服务的芯始终跟随 2023-2026 年的模型浪潮——这是其四年后仍有 15k+ 星的关键。
信源：[2] [11]
转折三：免费开源作为「进攻性定价」——正面卡位 ¥58 买断市场
Bob 的商业化路径是免费版 + Pro 买断（¥58，案例墙既有核验值），而 Easydict 选择完全免费：无版本分层、无试用、无付费功能墙[6]，用户自带各家 API 密钥（BYOK），工具本身零抽成。2023 年 4 月 V2EX 帖子里最真实的情绪是——多名刚花 ¥58 买断 Bob Pro 的用户发现「免费的这个更好用」[7]。免费不是没有代价：项目收入只剩爱发电赞助[2]，规模未公开。这是一条以社区声誉为资产、以个人时间投入为成本的路径。
信源：[6] [7] [2]

产品与商业模式

Product & Business
维度Easydict 的做法说明
产品功能开箱即用 · 多引擎并查 · 离线 OCR开箱即用、自动识别语言，输入/划词/截图三种触发方式，可同时查询多个服务并列对比结果；静默 OCR 直出剪贴板；多 TTS 发音；52 种可选语言[2]
与 Bob 的差异化定位免费开源（GPL-3.0） vs 付费买断（Bob Pro ¥58）初始版本即基于 Bob（GPL-3.0）分支开发，功能与 UI 大量参考 Bob；分叉后以「完全免费 + BYOK 零抽成」形成对位竞争——Bob 靠 Pro 版持续销售，Easydict 靠免费换社区声望[2]（Bob 定价为案例墙既有核验值）
面向客群macOS 用户 · 开发者/研究者 · 隐私敏感者日常阅读外文文档的 macOS 用户；需要并排比较多个引擎的翻译者；不愿为付费 OCR 工具买单的用户；希望翻译数据不出本机的隐私敏感人群（Ollama 本地模型路线）[6][12]
解决痛点付费门槛 · 引擎切换成本 · 图片取词 · 数据外发顾虑把付费 OCR 工具的收费功能（截图提取文字）与翻译合三为一且免费；一个快捷键同时问多个引擎，免除逐家配置与切换；离线 OCR 本机完成、可经本地模型实现全离线翻译[6][2]
📌 商业模式留白说明
Easydict 无付费版本与内购，README 明确「免费开源项目，主要由作者本人开发维护」，赞助入口为爱发电[2]；赞助金额、月度收入、成本结构均未检索到公开信息。本项目在案例墙中的「成功迹象」以社区关注度（GitHub 星标、安装量）为主，而非营收指标——如实标注，不推算营收。

七维深度分析

Seven Dimensions
维度分析
1. 产品功能（含 OCR 离线隐私优势）开箱即用 + 自动语言识别 + 三种触发方式 + 多引擎并列结果，构成「输入翻译/划词/截图 OCR」一体化的菜单栏工具[2]。隐私是结构性优势：截图 OCR 在本机完成，不上传图片；翻译环节可接入 Ollama 本地模型实现「文本不出机」，独立评测认为这对翻译合同、病历等敏感文本是「与粘贴进网页输入框完全不同的命题」[6]；中文第三方指南同时提醒：OCR 离线 ≠ 整条工作流离线，在线引擎仍会将文本发往对应服务器，需按启用的服务自行判断[12]。
2. 面向客群直接客群为 macOS 13+ 用户中的高频跨语言阅读者（研究者、开发者、多语言职场人）、翻译质量敏感者（需要多引擎对照）与隐私敏感者[6]；间接客群是自带 API 密钥的重度 AI 用户——OpenAI/Gemini/DeepSeek/Ollama 等服务清单实质上面向「已经拥有大模型 API」的人群[2]。Windows 用户是持续外溢的需求方（社区最高频抱怨之一）[6]。
3. 解决痛点①价格门槛：把付费 OCR 应用收费的「图片取文字」功能与翻译合并且免费，r/macapps 社区的经典场景是「每当付费 OCR 促销，评论区总有人甩出 Easydict 并附上 free 一词」[6]；②引擎切换成本：一个快捷键同时问 DeepL、Google 和大模型，并排对比分歧[2]；③信任成本：GPL-3.0 源码可审计，规避闭源翻译工具的权限黑箱顾虑[6]。
4. 预估年化营收（推算，置信度 C）直接营收 ¥0无付费版本、无内购、无广告，唯一收入通道为爱发电赞助，金额未公开——未检索到公开营收信息，不作推算[2]。其「回报结构」需换算为非货币资产：15.3k 星的行业声望、79 名贡献者的社区网络、以及作者在开发者社区的个人品牌（403 名 GitHub 关注者）[3][13]。
5. 融资进展无融资记录、无公司主体信息公开。非货币资源支持：社区开发者 CanglongCl 提供 Apple 开发者账号解决签名难题（issue #2），使普通用户绕过手动信任开发者证书的门槛[2]——开源项目的「融资」往往以这种资源置换形式出现。
6. 市场评价社区正评价密集且具体：2023-04 V2EX 帖 1.6 万次点击下，「调用出来反应更快」「巨好用」「神器」层出，多名 Bob Pro 付费用户自嘲「买早了」[7]；r/macapps 高赞推荐帖（334 赞）称「Love easydict」[6]；独立评测 8.2/10，评语「罕见的在能力而非价格上超越付费竞品的免费工具」[6]。负评价同样真实：有 V2EX 用户批评其（当时）不支持自定义 prompt、内存占用「是 Bob 的三倍多」（单一用户观点，未见实测复核）[9]；评测列出的短板还有 BYOK 配置门槛、文档中文优先英文滞后、快捷键冲突、设置项繁多[6]。
7. 开源维护可持续性与合规单人维护的可持续性有真实证据也有真实信号：正面是一年 12 个版本的发版节奏与四年间歇不断的代码推送[10][1]；风险是作者在 README 明言「最近很忙，通常只能在周末处理 issue」，PR（尤其修 bug 类）优先[2]——单点维护瓶颈显性存在。对冲机制有二：其一，生态分摊——Raycast 扩展已转交 maxchang3 维护[5]，Windows 端出现社区移植版「Easydict for Windows」（18+ 服务，上架 Microsoft 应用商店）[14]；其二，贡献者达 79 人[13]，README 还明确欢迎 Codex/Claude 等 AI 编程助手辅助贡献[2]。合规面：GPL-3.0 协议，README 特殊声明「仅供学习交流使用」，并附「若认为权益受侵可联系作者」条款[2]；其本身就是从 Bob（GPL-3.0）合规分叉而来，协议链条清晰。

本案的样本价值
Easydict 证明了 OPC 模式的另一极：不追求营收、不融资、不注册公司主体，以「GPL 分叉 + 彻底免费 + 跟随模型浪潮」在巨头与付费产品夹缝中建立事实标准级的个人作品。它的资产表上没有现金流，只有 15.3k 星、79 名贡献者与四年的发版记录——对一人公司而言，社区声望本身即是可以长期复利的资产负债。它同时提醒：这条路径的可持续性完全押注在单点维护者的时间与热情上，README 里那句「通常只能在周末处理 issue」，就是免费开源模式成本结构的真实注脚。
