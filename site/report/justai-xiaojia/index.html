案例档案

Case Profile

JustAI 的「小加同学」是国内「AI 一人公司」叙事中被主流媒体确认的 B 端工具型代表：一款面向中小商家与本地门店的 AI 内容营销 Agent——商家上传产品图+一句产品描述，约 1 分钟生成推广图文、标题、封面与种草物料，上线一年注册用户达 400 万。本案例按 OPC 双口径收录：一人属性为「创始人主导+少量协作」（详见捌章口径注记）。

产品
AI 内容营销 Agent「小加同学」：商家上传产品图+一句产品描述，约 1 分钟生成推广图文、标题、封面与种草物料；定位中小商家与本地门店的内容营销产能工具。
信源：[1] [4]
创始人
卢冠男 Lucas，95 后，东南大学软件工程专业；曾在腾讯等大厂工作约七年；2025 年中辞职，在深圳南山以 OPC 模式创立 JustAI。
信源：[1] [2] [4]
用户与商业化
上线一年注册用户 400 万、付费客户 1 万（南都 2026-08 口径）；官网口径另有「上万商家」。注册用户官网时序：300 万 → 350 万+ → 400 万。
信源：[1] [4]
行业亮相

信源：[5]

创业路径复盘

Key Turns
转折一：七年大厂工程履历，是 OPC 模式的技术底气
科班软件工程 + 腾讯等大厂约七年，意味着产品架构、工程实现、AI 技术集成可以由创始人独立完成——「一个人做 Agent 产品」首先是一个工程能力命题。这是本案例与「零代码搭工具」型独立开发者的本质区别：JustAI 交付的是持续运行、面向 B 端的完整 Agent 服务。
信源：[1] [2]
转折二：赛道选择——中小商家的内容营销产能缺口
电商与本地门店需要高频产出图文/种草物料，但请不起文案与设计团队；「产品图+一句话 → 约 1 分钟全套物料」把专业内容产能平民化。上线一年 400 万注册用户的规模，从需求侧验证了这个切口真实存在——选「高频、低价、标准化」的内容生产环节，是 Agent 产品能快速起量的关键。
信源：[1] [4]
转折三：免费获客 + 付费变现的漏斗
注册 400 万、付费客户 1 万——按披露数字直接推算，免费→付费转化率约 2.5%（推算口径，见柒章）。低门槛免费生成承担获客，付费层承接有稳定内容产能需求的商家；客单价与付费结构未披露，是本案商业化评估的最大留白。
信源：[1]
转折四：把「一人公司」身份本身当作品牌资产经营
从官网媒体合集页（2026-06）到 WAIC 2026 OPC 专属展区（2026-07）再到南都专访（2026-08），创始人系统性地把 OPC 叙事产品化：对获客而言，「一个人做出 400 万用户的产品」本身就是最强传播点——身份即营销。
信源：[4] [5] [1]

七维深度分析

Seven Dimensions
1. 产品功能
AI 内容营销 Agent「小加同学」：商家上传产品图+一句产品描述，约 1 分钟生成推广图文、标题、封面与种草物料——覆盖中小商家线上营销最高频的内容生产环节，交付物可直接投放使用。
[1] [4]
2. 面向客群
中小商家与本地门店——缺乏专业文案/设计人手、需要高频产出投放素材但对成本极度敏感的长尾商家。B 端长尾客群决策轻、单价低但基数大，与「免费生成+付费增值」的漏斗模型匹配；用户画像细分数据未披露。
[1]
3. 解决痛点
传统内容营销需要文案+设计+运营多人协作，小商家请不起团队、外包成本高、周期长；「产品图+一句话 → 1 分钟全套物料」把专业内容产能平民化，用 Agent 替代一个小型内容团队——400 万注册量级从需求侧验证痛点真实存在。
[1] [4]
4. 预估年化营收（推算，置信度 C）
年化营收零披露：付费客户 1 万（南都口径），但客单价、付费方式（订阅/按次/买断）与续费率均未公开。可由披露数字直接推算的仅有免费→付费转化率约 2.5%（1 万 ÷ 400 万，算术推演）；若引入外部客单价假设即可得出营收区间，但在无任何定价披露前，本报告不引入外部假设数字。营收量级待官网披露或融资信息回填。
推算依据：[1]，推算口径为 C 级

融资信息未披露：未检索到任何公开的融资轮次、投资方或金额信息；商业模式依赖自身造血。非货币资源：WAIC 2026 OPC 专属展区的行业曝光位、南方都市报/南方+N 等主流媒体的一手报道背书。

6. 市场评价
媒体评价正面且层级高：南方都市报以一手专访将其作为 AI 一人公司样本报道；南方报业旗下南方+N 视频跟进一手采访；广州网信办（政府官网）转发南方日报系报道；WAIC 2026 设 OPC 专属展区收录本案——「一人公司+AI 数字员工」模式获行业会展与主流媒体双重确认。用户侧评价（应用商店评分、社交媒体口碑）未检索到系统性数据。
[1] [2] [3] [5]
7. 投入成本与合规风险
成本：团队为创始人+全职员工 4 人+实习生（南都口径），人力结构远小于同等用户量级的传统团队；具体投入金额、算力与模型 API 成本未披露。合规维度：① AI 生成的营销素材在公开传播场景下负有内容标识与合规义务（适用国家网信部门 AIGC 生成合成内容标识相关规定）；② 生成内容用于商业推广时受广告法真实性要求约束——生成图文与真实商品的一致性由商家把关，平台方需在服务协议中界定责任；③ 商家上传产品图涉及商业信息与图片版权处理，数据安全与授权链条是 B 端工具的长期合规项。以上为行业通识性风险讨论，未检索到针对本案的监管处罚记录。

「400 万注册用户」如何解读
注册 ≠ 活跃 ≠ 付费：本案未披露 DAU/MAU 与留存数据；免费注册的低门槛工具品类中，注册量通常显著高于活跃量级——引用该数字时应保留「注册」限定词，避免与活跃用户混同。1 万付费客户（转化率约 2.5%，推算）是更接近商业实质的指标，但其客单价与续费数据仍属留白。此为解读提示，不构成对本案数据真实性的质疑。

本案的样本价值
JustAI 是国内「AI 一人公司」叙事中 B 端工具型的代表：以 Agent 承担内容产能、以创始人工程能力替代技术团队、以少量协作补足运营。其 OPC 身份已获行业会展（WAIC 2026 OPC 专属展区）与主流媒体（南都专访、政府官网转发）双重确认——提示「创始人主导+少量协作」正成为国内一人公司的主流形态之一，与严格单人创作型案例（如泫九《归墟》）共同构成 OPC 光谱的两端。
