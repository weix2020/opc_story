案例档案

Case Profile

Bob 是一款 macOS 平台的翻译和 OCR 软件，在任意应用程序中即可划词翻译、截图翻译与截图 OCR，「即用即走」[1]。它是国内「买断制工具型一人公司」存活时间最长的样本之一：2019 年底发布第一个版本，2022 年转为付费并上架 Mac App Store，此后在免费开源竞品的正面夹击下，以 ¥58 终身买断持续销售至今。

产品
macOS 翻译 + OCR 双核工具：划词翻译（⌥+D）、截图翻译（⌥+S）、输入翻译，支持最多 12 路翻译服务同时对照；OCR 支持截图 / 静默截图 / 访达选图、离线识别、连续识别、二维码识别与智能分段；1.0.0 起上架 Mac App Store，免费下载、内购解锁 Pro。
信源：[1] [2]
创业者
ripperhe：GitHub 资料显示坐标 Beijing China、bio「iOS / macOS Developer」，账号 2015-08-24 注册，真名字段未公开。Mac App Store 开发者账户显示「宗苡 何」，应用版权「© 2019 Zongyi He」、bundleId 为 com.hezongyidev.Bob——三处实名信息相互印证，但本人未以真名公开自我介绍。
信源：[3] [2] [4]
商业模式
免费下载 + Bob Pro ¥58.00 内购终身买断（另设 Bob Free Trial ¥0.00，官方博客称提供 14 天免费试用）；用户自带各翻译/OCR 服务密钥（BYOK），官方 FAQ 明确「终身买断制，只需一次付费」，并承诺「Bob 不会收集和上传你的服务密钥」。
信源：[2] [5] [6] [7]
公司 / 融资状态

信源：[2] [5]
AI 服务接入（本案例入选案例墙的关键）
官网「申请服务」页列出 33 项文本翻译服务，其中 20+ 为大模型 / AI 服务：OpenAI、Azure OpenAI、Claude、Gemini、Grok、DeepSeek、豆包、通义千问、文心一言、Kimi、智谱 GLM、混元、硅基流动、Ollama、LM Studio、OpenRouter 等；另有 6 项 OCR 与 4 项语音合成服务。
信源：[7] [1]
AI 契合定位
GitHub 仓库 topics 直接标注 openai、deepseek、doubao、ernie、gemini、groq、hunyuan、kimi、qwen、zhipuai 等模型关键词；Bob 本体是「聚合前端」——AI 模型作为可插拔的翻译/OCR 引擎被接入，产品形态为 ai-embedded（AI 为既有工具的核心增强能力）。

创业路径复盘

Key Turns
转折一：两年半免费养成 → 终身买断的「有诚意一跃」
2019 年底到 2022 年 7 月，Bob 以开源免费形态迭代了十几个版本，先在开发者社区攒下口碑（V2EX 万次点击）。转付费不是断崖式收费，而是一套完整的迁移设计：①14 天免费试用再决定；②社区版保留可用（只是停止维护）；③早期赞助者全额兑换码回馈；④公开解释定价逻辑——「购买 Pro 的费用用于软件开发、维护、文档编写以及客户支持的时间成本」。付费版承接的正是免费期积累的信任。[5][6][11]
转折二：AI 翻译浪潮的两次卡位
第一次（2023）：OpenAI 自定义 Prompt + Azure OpenAI 接入，让 Bob 在 GPT 热潮里保住了「能用上最新翻译能力」的身价；第二次（2025-01）：一个版本内接入 12 家 AI 服务，此后逐季度跟进模型代际（GPT-5/gpt-5.2、gemini-3、GLM-4.7、Qwen-MT、doubao-seed-translation 等翻译专用模型）。一人公司的护城河被证明是「适配速度」——大厂单品不会为聚合 30+ 服务持续做脏活，而用户恰恰要这个。[12]
转折三：免费开源竞品夹击下的买断存活
2022-11 Easydict 立项，其 README「初衷」写道：Bob 是优秀的翻译软件，「但它不是开源软件，自从上架苹果商店后也不再免费提供应用更新……这世界上应该存在一个免费开源版本的 Bob，于是我开发了 Easydict」——直接以 Bob 为对标。此后四年两版并存：Easydict 涨到 15.3k★（2026-11-13 API 实测，超过 Bob 的 9,759），而第三方横评仍把 Bob 列为「Mac 上划词翻译体验最好的一个」。买断制工具在免费替代品面前的存活逻辑：持续适配、原生体验、文档与客服的确定性。[14][15]

软件本身不算难，但是需求开发、撰写文档以及处理反馈都需要花费不少的时间，为了我能有动力把 Bob 做得更好，从这一刻开始，Bob 正式成为一个付费应用。

—— ripperhe，《Bob 1.0.0 正式发布啦！》（2022-07-03，官网博客），转引自 [5]

七维深度分析

Seven Dimensions
1. 产品功能
「翻译 + OCR」双核的原生 macOS 工具，一切交互围绕快捷键与悬浮窗完成；产品即工具本身，不含社区、云同步或账号体系。功能演进高度克制：七年主线只有三条——翻译源越接越多（3 家 → 33 项服务）、OCR 越来越强（联网 API → 离线 → 自研 V2 算法）、交互方式补全（静默划词、原图翻译）。[12] [7] [9]
2. 面向客群
核心客群是 macOS 效率用户中「读外文材料的人」：科研党、开发者、英语文档阅读者。特点是不需要教育成本（翻译是刚需且高频）、付费意愿分散但单价敏感（学生与个人用户为主）、对隐私敏感（自带密钥）。用户评论区「科研党」「从社区版过渡到升级版」的自述与该画像吻合。[2]
3. 解决痛点
①传统词典/翻译 App 打断心流——Bob 让翻译发生在任何 App 的选中文本上；②截图里的文字无法复制——OCR 直出；③各家 AI 翻译质量参差且入口分散——12 路同屏对照、一个界面切换 33 项服务；④API Key 安全顾虑——官方承诺密钥仅存本地不上传。[1] [7]
4. 预估年化营收（推算，置信度 C）
销售数据零披露，任何具体收入数字都属编造，本报告只给敏感性框架：Bob Pro 标价 ¥58，每多 1,000 份授权 ≈ ¥5.8 万毛收入（未扣苹果内购分成与兑换码成本）；若七年累计 1 万份授权，量级为数十万元；2-3 万份则接近百万元——均为纯假设推演。可核验的间接信号只有两个：开发者七年不间断投入（机会成本为正收益的必要条件），以及买断制在 FAQ 中被反复维护而非转向订阅。[2] [4] [6]
5. 融资进展
无任何融资或公司注册的公开信息；以个人开发者账户（宗苡 何）上架。非货币资源：早期用户赞助（转付费时以兑换码回馈）与第三方服务的免费额度合作（智谱 GLM-4-Flash、硅基流动 Qwen 等模型对 Bob 用户免费开箱即用——上游厂商借 Bob 触达用户，Bob 借上游省去自研模型成本，双向借力）。[2] [5] [12]
6. 市场评价
正面：V2EX 发布帖「不是 electron，好评」（原生性能口碑）；第三方横评（2026-07）列 Bob 为翻译类「★ 起步推荐」，称「Mac 上划词翻译体验最好的一个……内存占用低」；连竞争品 Easydict 的作者也在 README 中称 Bob「是一款优秀的翻译软件」。中性/负面：中国区 App Store 评分样本不足无法显示总分（小众付费工具的常态）；开源社区始终存在「为什么收费」的质疑空间——Easydict 的立项理由本身就是这种情绪的凝结。[9] [15] [14] [2]
7. 投入成本与合规风险
成本结构：无服务器、无内容成本，唯一投入是本人时间——但维护面极宽：33 项上游服务的 API 变动（百度、小牛、金山词霸数年间的多起调整均需公告应对）、每个 macOS 大版本的兼容（macOS 15/26 的 Option 键失效是系统级 bug，「软件无法修复，只能规避」）、每年数十个版本的开发与文档。合规面：翻译工具无内容牌照问题；隐私面 App Store 声明仅收集「使用数据、诊断」且不关联身份，密钥不出本机——工具型 OPC 的合规负担显著轻于内容型。[10] [13] [2] [7]

本案的样本价值
Bob 证明了中国个人开发者「买断制长生意」的一条窄路：用两年半免费建立信任 → 一次性低价买断（把 AI 用量的成本诚实地留给用户的密钥）→ 以一己之力维持对 30+ 上游服务和每代 macOS 的持续适配 → 在免费开源竞品直接对标的情况下，靠原生体验、文档、客服与适配速度守住付费位。它不性感、不爆发，但七年未死——这恰是工具型 OPC 最真实的那条生存曲线。
