案例档案

Case Profile

ChatNio 是 2023 年初由一名山东七年级学生 zmh 发起的「多模型对话 + API 中转/计费管理」一站式开源平台：从让朋友免费用上 GPT-4 的公益项目起步，靠「高性价比 + 功能全面」零投放增长到近 10 万月活，2024 年被以七位数（人民币）收购并更名 CoAI.Dev——它是本案例墙中唯一走完「开源 → 商业化 → 并购退出」完整闭环的开源产品型 OPC 案例，创业者全程未成年。

项目
ChatNio（收购后更名 CoAI / CoAI.Dev）：聚合多模型对话、AI 助手预设、文生图、联网搜索、文件解析与 OpenAI 兼容 API 网关、弹性计费后台。机器之心口径接入 OpenAI、Midjourney、Claude、讯飞星火、Stable Diffusion、DALL·E、ChatGLM、通义千问、腾讯混元、360 智脑、百川、火山方舟、Gemini、Moonshot 等 35 款模型；收购后仓库自述「200+ 模型、35+ 提供商」。GitHub 页面 slogan：Chat Nio > Next Web + One API。
信源：[5] [4]
创业者
zmh，网名 zmh-program / ProgramZmh，现用名 Kairo；CSDN 报道称其 2009 年出生、英文名 Minghan Zhang（中文名未在公开信源确认）。山东重点高中在读（信息小组背景），个人站点自述 8 岁起编程（Minecraft Forge 模组）。发起 ChatNio 时为初中生（七年级下学期，约 13-14 岁），收购交接时 15 岁、刚上高一。
信源：[6] [3] [2]
成功迹象
2024 年被七位数（人民币）收购——腾讯新闻·新榜口径「被百万元收购」，机器之心/CSDN 标题口径「数百万元」；截至 2024 年 11 月，累积近 10 万月活跃用户、每月 5 万元净利润（腾讯新闻引用其自述）；2024 年初自述口径为 100k+ MAU、¥20 万 MRR、~¥5 万月盈、团队 4 人。GitHub 现存 9,346 stars（2026-11-12 API 实测）。
信源：[1] [5] [2] [4]
公司 / 收购状态
未成年开发者身份成立：项目发起、开源、商业化全程在初中阶段完成。2024 年中考后完成收购交接（软著转移、权限分配），项目更名 CoAI.Dev，zmh 以创始人身份继续主导开发，媒体普遍称其出任 CTO；收购方主体未公开披露，是否注册公司主体未检索到公开信息。

创业路径复盘

Key Turns
转折一：从「自费开源」到四档商业化阶梯
资金链的演进路径清晰：接几千元小单养服务器（自费开源）→ 用户暴涨后公益免费撑不住 → 社区投票转「非盈利」并开源共建 → 免费 / 个人版 $5/月 / 公司版三档订阅 + 商业授权版源码（私有化部署）。每一次模式切换都不是拍脑袋，而是成本结构倒逼的结果——这台「一个人公司」的财务模型在初中生手里跑通了完整的阶梯。
信源：[2] [5]
转折二：不做 NextChat，也不做 One API——融合层的卡位
zmh 自述开发前系统分析了市场上两类玩家：偏前端轻量部署的项目（如 NextChat，UI 精美但私有化倾向、二开商业化受限）与偏 API 分发的项目（如 One API，分发强但缺界面、缺 C 端功能）。ChatNio 以「Chat Nio > Next Web + One API」直接把对标写进 slogan，自研渠道分配算法（优先级、权重、报错自动降级）——而当时 One API 还只靠外部 HTTP 307 重定向降级。产品上的「两边都要」，正是它能同时收 C 端订阅与 B/D 端网关生意的原因。
信源：[6] [5] [2]
转折三：零推广增长 + 「中考优先」的克制
从始至终零宣传、零推广分成，10 万月活全部来自「用户推用户」；唯一一次曝光是朋友 2024 年 2 月在 V2EX 代发分享贴。临近中考主动停更宣传，收购交接刻意安排在中考后完成——时间线高度「学期化」。这种克制既是未成年的现实约束，也客观上保护了产品口碑：增长全部来自产品力而非营销噪音。
信源：[2] [9]

当时 ChatGPT Plus 才能用 GPT4，要每个月订阅费 20 刀，对于大多数（非一线城市的）初中生来说每个月拿出来 140 多块是几乎不可能的，但是我当时有一定的收入来源，于是我开启了这个项目分享给我的朋友们一起使用。

七维深度分析

Seven Dimensions
维度核心事实与分析信源
1. 产品功能「对话产品体验 × API 网关基建」双层结构覆盖 C/B/D 三端：多模型聚合、AI 助手市场、文生图、联网搜索、Blob 文件解析、模型缓存、弹性计费、渠道管理；社区版 Apache-2.0 与商业版源码双轨。单人完成 Vue3+Node.js → Go → React+Shadcn 两次架构改版，工程完成度在同类单人项目中居前。[4][2]
2. 面向客群C 端低价聚合用户（$5/月替代 35 款模型会员）、B 端私有化企业、D 端 API 经销商/站长。zmh 即刻答问确认主要付费场景为 API 经销商监控下游 usage 与企业管理员工 LLM 使用——即其现金流核心在 ToB/ToD，而非 C 端订阅。[2][5]
3. 解决痛点① $20/月 GPT-4 订阅对无收入学生群体过高；② 多模型会员分散、总价高；③ NextChat 与 One API 各缺一端的「融合空位」。三个痛点都来自创业者自身的真实处境（初中生 + 朋友群体），需求洞察的成本几乎为零——这是学生创业者的结构性优势。[2][6]
4. 营收与商业模型2024 年初自述 MRR ¥20 万、月净利 ~¥5 万（年化营收约 240 万量级、净利率约 25%）；腾讯新闻口径截至 2024-11「每月 5 万元净利润」。叠加七位数并购对价一次性变现。置信度 C：全部为自述口径、未经第三方审计，且为收购前峰值而非持续值。[1][2][7]
5. 融资与资本运作无公开机构融资；自述曾接触真格基金、YC、奇绩创坛、绿洲资本、蓝驰创投等 VC（一起会议与 casual 交流）。最终未走融资路径，而以七位数并购退出——本案是案例墙中罕见的「未成年 + 并购退出」完整闭环，退出时点与中考同步。[2]
6. API 中转合规三重灰色地带：① 公益期自述钻研「开虚拟卡、过 arkose、逆向、sess」等手段供给模型能力，处于平台服务条款的边缘；② 国内 API 中转/转售大模型服务长期缺乏针对个人站长的清晰监管指引（模型来源授权、内容安全责任、计费与实名），行业整体游走灰色；③ 开源版 Apache-2.0 与商业版的双轨授权边界依赖自觉。截至检索日未检索到针对 ChatNio 本身的监管处罚或诉讼记录。[2][4]
7. 未成年创业的学业平衡时间线高度「学期化」：暑假开源建仓、九年级年初冲到数据高点、中考前主动停更宣传、中考后完成收购交接——学业节点反向定义了商业节奏。自述父母最初不支持学计算机，其策略是「两头抓」：用班级年级第一、市优秀学生的成绩换取空间，再用项目收入争取话语权；16 岁时站点仍以学生身份自居，是否全职、是否注册经营主体均未披露。[2][3][7]
🔎 维度间的因果链
痛点（同学用不起 GPT-4）→ 产品（融合层 + 低价）→ 客群（D 端经销商复用同一套网关）→ 现金流（MRR ¥20 万）→ 退出（七位数）。每个环节都被「一个人」的约束形状塑造：没有融资所以必须自我造血，没有团队所以架构改版只做两次，没有时间所以零推广、中考优先。ChatNio 是「约束即战略」的教科书样本。
