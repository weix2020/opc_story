案例档案

Case Profile

Chat Memo 是一款把散落在 ChatGPT、Claude、Gemini、DeepSeek、豆包、腾讯元宝等平台上的 AI 对话「自动存档为个人记忆资产」的浏览器插件：后台静默增量保存、侧边栏全库检索、一键导出，全部数据 100% 存储在用户本地设备。它由 AI 领域知名作者一泽 Eze 一人开发并运营，2025 年 6 月 30 日经即刻与公众号正式发布，是国产「AI 对话资产管理」赛道最早跑出规模声量的个人作品之一。

产品
浏览器插件，Chrome 与 Edge 双商店上架（开发者署名一泽Eze / Eze）。核心能力三层：① 自动存档——后台静默增量保存，连重新编辑、重新生成后的消息也同步收录；② 全库检索——按标题与消息全文搜索，含 AI 思考（Think）过程，可跳回原对话；③ 记忆中枢——卡片式管理、批量导出、一键复制到其他 AI 续聊，官网另附「AI 互动周报 / 主题回顾 / 自我洞察」三套玩法配方。
信源：[1] [3] [4] [5]
创业者
一泽 Eze，行业知名提示词工程作者（单条 Prompt 全网浏览量 10w+）、WaytoAGI 社区专栏作者、LangGPT 开源社区共建者，曾参与制定多项行业标准与白皮书。WaytoAGI 官方介绍页口径为「现任某 B 端独角兽公司产品总监、前大厂运营负责人」；其自述以 AI 博主身份年评测数十款模型与产品，每天与 AI 对话 8 小时以上。注：案例底稿所载「前阿里工程师」未获直接信源印证，正文按可核验口径呈现（详见捌节④）。
信源：[4] [7] [1]
开发方式
自称「完全用 AI 的 AI 做的 AI 产品」：产品开发、官网设计、发布计划历经 6 个版本、几度重构，均由其与 AI 协作完成，全程无需外部团队；插件自身完整记录了自立项以来的全部 AI 共创过程——产品哲学与开发方法互为证明，是「AI Coding 自举」的典型样本。
信源：[2] [3] [4]
公司 / 融资状态
未检索到公司注册与融资的公开信息；产品以个人名义在两商店上架，隐私政策公开托管于其个人 GitHub 仓库，第三方工具目录收录条目显示「运营中」。截至核验时点（2026-11-12），核心本地功能永久免费，付费增值服务（Pro）处于规划征集阶段。

创业路径复盘

Key Turns
转折一：从「评测别人」到「被审视」——个人 IP 的第一次产品化变现
发布 Chat Memo 前，一泽以 AI 博主身份评测过数十款模型与产品，靠 10w+ 阅读的提示词文章与 WaytoAGI 专栏积累了精准的 AI 重度用户读者盘，且在 Prompt → Context Engineering 议题上保持持续输出。产品上线即有冷启动：即刻发布帖评论区出现 Demo Day 邀约与平台需求投票，「为包括自己在内的重度用户做工具」让需求洞察与分发渠道天然重合——这是「个人 IP + 垂直插件」路径的起点：先用内容锁定人群，再为人群做产品。
信源：[2] [4] [7] [11]
转折二：AI Coding 的「自举」——用自己的方法论做出自己的产品
6 个版本、几度重构，开发、官网、发布全部与 AI 协作完成；自动保存功能「打磨了数十轮代码才终于有了市面上体验最丝滑的版本」。更有意味的是产品与方法的闭环：Chat Memo 自己记录了它从混沌构想 to 发布方案的孵化全程，作者在写发布文章时直接翻阅插件里的时间轴对话卡片取材——提示词/Agent 工程经验直接转化为产品工程能力，且产品本身成为方法论的展品。
信源：[2] [3] [4]
转折三：隐私优先的架构选择——把「数据主权」做成产品本身
面对即刻评论区「聚合数据存在哪」的第一质疑，作者的回答是架构级的：IndexedDB 100% 本地存储、无限制导出、「绝不不经用户允许做其他处理」，隐私政策公开托管在 GitHub 供审计。「你的数据只属于你」既是获客卖点（区别于一切云端记录类产品），也是信任壁垒——但同时构成商业化的隐性天花板：未来任何云端增值服务都要用户把数据重新交出来。
信源：[2] [1] [6] [5]

七维深度分析

Seven Dimensions
维度分析
1. 产品功能三层递进：自动增量存档（无感，同步重编辑/重生成消息）→ 全库检索（含 AI Think 过程，跳回原对话）→ 记忆中枢（周报/主题回顾/自我洞察配方，向「理解你的意图并主动回忆」演进）。功能边界清晰：不做 AI 对话本身，只做对话的资产管理层。[1] [5] [4]
2. 技术实现浏览器扩展架构：内容脚本监听各平台网页对话流 + IndexedDB 本地存储 + 增量更新；中英双语；Chrome/Edge 双端。难点不在算法而在适配：每个平台网页结构各异且频繁改版，保存体验靠数十轮打磨。开发过程本身由 AI Coding 主导（6 个版本几度重构），是一人公司以方法论换工程能力的实例。[6] [5] [4]
3. 变现模式当前为零收入免费产品：核心本地功能永久免费，付费增值（加密云同步、AI insights）停留在官网 FAQ 的规划口径，Pro 意向表单已开放但未见上线。变现前提是用户愿意把「坚决留在本地」的数据重新交到云端——与隐私承诺存在内在张力，转化逻辑尚待验证。[1]
4. 面向客群AI 重度用户（每天与 AI 对话数小时的知识工作者），与创作者的公众号/即刻/WaytoAGI 读者盘高度重叠——获客不靠投放靠信任溢出。Edge 商店评价显示客群横跨中国、日本、美国、法国等多地区，产品天然面向全球 AI 用户。[1] [7] [5]
5. 解决痛点「对话资产分散」四重痛：跨平台隔绝、检索困难、个别平台丢记录、手动导出依赖自觉。Edge 用户评价提供了痛点真实性的实锤——Gemini 超长对话崩溃后历史全失，「一直想找能自动备份聊天记录的插件」。[3] [4] [5]
6. 对话数据隐私
（本地存储 vs 云端）		全本地（IndexedDB）是本案最锋利的差异化：对话内容含工作机密与情感倾诉，「绝不不经用户允许做其他处理」直击聚合类记录产品的信任死穴；隐私政策公开托管 GitHub 可审计。但隐私是双向刀刃：即刻评论区「公司电脑敢不敢装」「要不要加密码」的讨论说明本地聚合同样制造新的暴露面；而未来云同步增值必然要求用户推翻「数据不出本地」的心理预设——隐私卖点越成功，云端变现越困难。[2] [1] [6]
7. 浏览器插件生态依赖存档能力寄生在各大 AI 平台的网页 DOM 之上，平台任何改版都是断供风险——v1.5.3 一次更新即同时修复 ChatGPT 改版导致的全线保存失效、部分浏览器启动失败、Claude 特定回复丢失三类问题，维护成本随支持平台数线性增长。更深一层：若各平台原生记忆/搜索能力持续增强（或官方推出导出聚合），第三方存档层的价值将被结构性挤压；同赛道已有 LLMnesia、AI Memory、Chat Lens 等竞品以「更强搜索」「记忆注入」等差异点进攻。[5] [9]

① 商业闭环未验证：核心功能永久免费，Pro 增值（加密云同步、AI insights）截至核验仍为官网规划口径，无任何营收披露，付费转化率无从评估；② 用户数与评分多口径：官网 20000+ 用户/4.9 分 vs 第三方镜像 10000 用户/4.6 分 vs 竞品站 4.7 分——镜像快照时点不明，差异疑为增长时间差，引用时以官网口径并注明时点为宜；③ Chrome 商店页未能直接核验：商店页与 Wayback 快照抓取均返回空（反爬），评分/精选认证经 Edge 商店用户评价、竞品对比页、第三方镜像三路间接印证；④ 创业者背景口径差异：案例底稿所载「前阿里工程师」未获直接信源印证，可核验的官方介绍（WaytoAGI 介绍页）为「现任某 B 端独角兽公司产品总监、前大厂运营负责人、行业知名提示词工程师」，正文按后者呈现，特此存档。
🔍 需要持续观察的三个信号
① 平台改版是常态而非意外：ChatGPT 改版曾导致保存全线失效（Edge v1.5.3 更新日志实证），支持平台越多、维护负担越重，单人维护的可持续性待观察；② 赛道竞争升温：AI 对话存档/记忆插件已有多个竞品入局，且大模型平台原生记忆功能持续增强，「存档层」的独立价值窗口可能收窄；③ 第三方信息质量参差：某竞品站将 Chat Memo 误标为「仅支持 ChatGPT」（与商店页一手记录不符），提示二手对标信息必须回溯源站核验。
本案的样本价值
Chat Memo 验证了 OPC 模式中「内容资产 → 工具产品」的转化路径：一个不写代码为生的提示词工程作者，用 AI Coding 把自己日常工作的真实痛点做成产品，靠读者信任完成冷启动，靠隐私架构和持续维护赢得商店高分与 Google 精选。它同时是一面镜子——免费、本地化、单人的组合让产品获得了信任与口碑，却也让商业化悬置：20000+ 用户与 ¥0 收入并存，正是「个人 IP + 垂直插件」路径在变现环节的真实中间态。下一阶段（Pro 上线与否、云端增值能否突破隐私心智）将决定它滑向 chatGPTBox 式的开源口碑样本，还是 Copilot for Obsidian 式的订阅变现样本。
